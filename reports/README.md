# Generated evaluation reports

Run `make evaluate` after full training to generate `metrics.json`, or `make smoke`
after downloading PathMNIST to generate `smoke-metrics.json`.

Generated reports in this directory are ignored by Git. The baseline evaluation
report is versioned as [`baseline/metrics.json`](baseline/metrics.json); see its
[evaluation and reproduction notes](baseline/README.md).

No placeholder scores or results from synthetic fixtures are published here.
